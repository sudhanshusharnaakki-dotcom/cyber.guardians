# 🛡️ Cyber Guardians

## AI-Powered Cybersecurity Platform

Cyber Guardians is an AI-powered cybersecurity platform designed to help users detect phishing links, suspicious messages, and potentially unsafe PDFs.

### 🚀 Features

- 🔗 Suspicious Link Detection
- 💬 Phishing Message Analysis
- 📄 PDF Safety Analysis
- 🤖 AI-Based Risk Detection
- 📊 Risk Score Calculation
- 🛡️ Safety Recommendations
- 🔐 User Signup & Login System

### 🧠 How It Works

1. User enters a suspicious message or URL.
2. FishShield AI analyzes the content.
3. The system detects phishing indicators.
4. A risk score is generated.
5. Users receive safety recommendations.

### 🛠️ Technologies Used

- Python
- FastAPI
- JavaScript
- HTML
- CSS
- SQLite
- Browser Extension API

To make cybersecurity simple, accessible, and understandable for everyone.
